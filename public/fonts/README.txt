Drop Gilroy font files in this folder. The CSS in src/styles/fonts.css expects these filenames (WOFF2 preferred for size, WOFF as fallback):

  Gilroy-Light.woff2
  Gilroy-Light.woff
  Gilroy-Regular.woff2
  Gilroy-Regular.woff
  Gilroy-Medium.woff2
  Gilroy-Medium.woff
  Gilroy-SemiBold.woff2
  Gilroy-SemiBold.woff
  Gilroy-Bold.woff2
  Gilroy-Bold.woff
  Gilroy-ExtraBold.woff2
  Gilroy-ExtraBold.woff

If a weight file is missing the browser will fall back to the next available family in the stack (Manrope from Google Fonts -> system sans-serif).
